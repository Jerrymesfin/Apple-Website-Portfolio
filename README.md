# Apple Website: HTML/CSS to React

This project began as an Apple-inspired webpage built with HTML and CSS.
I later converted it into React as part of my journey to learn React and improve my frontend development skills.

## Project Versions

- `original-html-css/` — The original webpage built with HTML and CSS.
- `react-version/` — The React version, built with JSX and reusable components.

## Technologies

HTML, CSS, JavaScript, React, and Vite.

## What I Learned

- Converting an existing webpage into React
- Building reusable components
- Managing images and CSS
- Improving layout, typography, and spacing

## Run the React Version

Open a terminal in `react-version` and run:

    npm install
    npm run dev
